01PUBLIC & GENERAL

Getting started

ChemQuest is a Grade 9 chemistry puzzle game for Android. The public website explains the game and provides an Android download link. The game includes five stages, three levels per stage, learning assessments and a completion certificate.

Step-by-step instructions

  1. 1

    Open the ChemQuest website in a browser.

  2. 2

    Choose Download Game to reach the Android download guide.

  3. 3

    Install the downloaded APK only if it came from your trusted ChemQuest source.

  4. 4

    Open ChemQuest on your Android phone.

02PUBLIC & GENERAL

Users and their roles

Students play the Android learning game. Authorized administrators manage assessment questions on the website. Visitors can read the public overview and download guide without signing in.

Step-by-step instructions

  1. 1

    Student: use the Android game and complete the learning activities.

  2. 2

    Administrator: sign in with an approved email/password to edit and publish assessment questions.

  3. 3

    Public visitor: browse the website and download instructions; no administrator account is required.

04STUDENT GAME

Downloading the Android game

The download button and QR both open the same Google Drive file provided by the ChemQuest team.

CHEMQUEST • DOWNLOAD
1   Download ChemQuest APK
2   Open in Android Downloads
3   Install → Open
Download: Google Drive game file

Step-by-step instructions

  1. 1

    Open the Download Game section or scan the QR code.

  2. 2

    In Google Drive, select Download; wait for the APK to finish.

  3. 3

    Open the completed download from your Android Downloads app.

  4. 4

    If Android requires permission for this source, allow it only after verifying the file is from your team. Revoke the permission afterward.

  5. 5

    Select Install, then Open. If the link says access denied, ask the game's distributor to update Drive sharing permissions.

16ADMIN PORTAL

Creating and editing questions

The question editor supports question type, stage, BOW level, question order, choices and a correct answer. BOW items may include a hint and explanation.

Step-by-step instructions

  1. 1

    Select the assessment category (Pre-test, BOW, Post-test).

  2. 2

    Choose the stage and, for BOW, the level and question order.

  3. 3

    Enter the question text, answer choices and correct answer.

  4. 4

    Add a hint and explanation for BOW when appropriate.

  5. 5

    Select Save draft. Review the question before publication.

17ADMIN PORTAL

Reviewing and publishing questions

Drafts do not automatically become student-facing assessment sets. Administrators must approve/publish content and use the corresponding set publication controls.

Step-by-step instructions

  1. 1

    Find the intended question in Question bank.

  2. 2

    Review the text, answer choices, correct answer and any validation warnings.

  3. 3

    Publish the approved question.

  4. 4

    For BOW, choose the stage/level and publish the approved level set or all ready sets.

  5. 5

    For Pre-test/Post-test, use the corresponding publication controls; avoid changes during active student attempts.

20PUBLIC & GENERAL

Troubleshooting and frequently asked questions

These are common user checks. If the issue continues, contact the ChemQuest development or administrator team.

Step-by-step instructions

  1. 1

    The download link does not open: verify internet access and Google Drive permission.

  2. 2

    The APK will not install: check Android compatibility and available storage.

  3. 3

    The Admin Login fails: confirm credentials and that the account is approved.

  4. 4

    No questions appear: check the published assessment set and network; do not assume changes sync into an active attempt.

  5. 5

    The game behaves unexpectedly: record the stage, level, time and screenshot for reporting.

About this guide

This manual covers the ChemQuest Android game and the administrator website. The diagrams are labeled illustrations of interface controls, not screenshots captured from a particular student device. Actual app screens can vary as development continues. This manual is intended for learners, authorized administrators and public visitors.

Security reminder: Administrator accounts and question answer keys must remain private. Student login to the administrator website is not needed.
