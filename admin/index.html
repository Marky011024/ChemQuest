What Is ChemQuest?

ChemQuest is a Unity-based Grade 9 educational puzzle game designed to make chemistry lessons engaging and understandable through interactive investigations.

ChemQuest Admin User Manual

For approved administrators managing Grade 9 Science Pre-test, BOW, and Post-test questions.

1. Sign in

  1. Open the ChemQuest Admin website.
  2. Enter your Firebase administrator email and password.
  3. Click Sign in securely. Only accounts authorized in Firestore can edit questions.
  4. Use Forgot password? if you need reset instructions.

2. Navigate assessments

  1. Use the Overview, Pre-test, BOW, and Post-test tabs.
  2. Select a stage. Only BOW uses a level.
  3. Search or filter by publication status in the Question bank.

3. Add or edit questions

  1. Select assessment, stage, level if BOW, and question order.
  2. Enter the question, choices, and correct answer.
  3. For BOW, add a hint and explanation where needed for scaffolding.
  4. Review the validation messages and click Save draft.
  5. For an existing question, use Edit. Saving edits returns it to Draft.

4. Preview and publish

  1. Click Preview to inspect the question and correct answer.
  2. Confirm teacher approval and check the warning messages.
  3. Click Publish, then confirm. Unpublish returns it to draft.
  4. For BOW in all 5 stages and 3 levels, approve and publish two questions per level, then publish the individual Unity set or all 15 sets together. Pre-test and Post-test are not synced.

5. Import, export and restore

  1. Click Download CSV template to see the required columns.
  2. Fill the template and save it as CSV UTF-8.
  3. Select the file, review validation, and click Import validated drafts. All imported questions are drafts.
  4. Click Export CSV backup and save the file securely; it contains answer keys.
  5. Use History to view available prior versions and restore one as a draft. Deleting a question also deletes its embedded revision history.

6. Safety and assessment integrity

  1. Use only Science teacher-approved questions.
  2. Do not edit or republish questions while student assessments are active.
  3. Keep exported CSV files private; they include correct answers.
  4. Use Sign out on shared or school computers.
  5. Stage 1 Level 1 BOW has an experimental approved-snapshot cache with offline fallback. Pre-test, Post-test, and other BOW levels are not yet synchronized.
